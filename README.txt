SETUP
-----
1. Open js/data.js.
2. Replace the sample phone number, email, Facebook URL, and Instagram URL.
3. In index.html, find:
   <!-- PUT MYSTIC GROVE LOGO IMAGE HERE -->
4. Replace the placeholder span with your actual logo image.

IMPORTANT
---------
The logo is intentionally NOT included in the webpage yet, as requested.

The Save Contact feature creates a standard .vcf contact file. A normal
website cannot silently add a contact directly to a phone's address book
without the user's confirmation.

For best results, upload the whole folder to your web host or GitHub Pages.
You can also open index.html directly for testing.
